Tu objetivo NO es simplemente construir una página web bonita.

> “Quiero seguir bajando para ver qué viene después.”

---

# OBJETIVO PRINCIPAL

Diseña y desarrolla una **Landing Page moderna, premium, persuasiva, visualmente atractiva y altamente optimizada para conversión**, utilizando:

**Next.js 16 + TypeScript + Tailwind CSS**

Debe sentirse como una web realizada por un estudio digital premium en 2026.

La página debe combinar:

**Claridad + estética + storytelling + interacción + velocidad + conversión.**

---

# PRINCIPIO FUNDAMENTAL DE DISEÑO

No quiero una Landing Page genérica construida como:

Hero → tres cards → beneficios → testimonios → footer.

Quiero que cada sección tenga intención.

La página debe contar una historia mientras el usuario hace scroll.

Cada sección debe responder alguna de estas preguntas:

* ¿Qué es esto?
* ¿Por qué debería interesarme?
* ¿Qué problema me resuelve?
* ¿Por qué es diferente?
* ¿Puedo confiar?
* ¿Cómo funciona?
* ¿Qué obtengo?
* ¿Por qué debería actuar ahora?

El diseño debe mantener **curiosidad visual entre secciones**.

# EFECTOS VISUALES

Quiero **efectos ligeros pero actuales**, que mejoren la percepción premium sin convertir la web en una demostración de animaciones.

Puedes utilizar cuando tengan sentido:

* Fade + translate suave al entrar al viewport.
* Stagger animations.
* Reveal animations.
* Text reveal discreto.
* Parallax extremadamente ligero.
* Elementos que reaccionen sutilmente al mouse.
* Cards con hover elegante.
* Glow localizado.
* Spotlight suave.
* Gradientes dinámicos muy discretos.
* Blur ambiental.
* Glassmorphism únicamente donde aporte valor.
* Bento grids.
* Sticky storytelling.
* Scroll progress.
* Elementos que cambien mientras se hace scroll.
* Números o métricas animadas.
* Before/after interactivo.
* Marquees extremadamente suaves.
* Infinite sliders únicamente cuando tengan sentido.
* Microinteracciones en botones.
* Magnetic effect MUY sutil.
* Background grid/noise ligero.
* Máscaras y overlays.
* Border animations delicadas.
* Transiciones suaves entre estados.
* Scroll-driven storytelling.

Evita:

* Animaciones exageradas.
* Elementos flotando sin propósito.
* Scroll secuestrado.
* Cursores personalizados molestos.
* Animaciones largas.
* Efectos que dificulten leer.
* Exceso de glassmorphism.
* Exceso de gradientes.
* Exceso de tarjetas.
* Todo moviéndose simultáneamente.
* Animaciones que reduzcan rendimiento.

El usuario siempre debe sentir que controla la navegación.

---

# REGLA DE ANIMACIÓN

Utiliza esta filosofía:

**80% interfaz limpia / 20% sorpresa visual.**

Las animaciones deben ser:

* rápidas;
* elegantes;
* naturales;
* funcionales;
* consistentes.

Utiliza curvas de easing naturales.

Respeta:

`prefers-reduced-motion`

Cuando sea posible, prioriza CSS animations/transitions.

Si necesitamos animaciones más complejas, utiliza una librería moderna y apropiada como **Motion / Framer Motion**, pero sin añadir dependencias innecesarias.

# HERO SECTION

El HERO es extremadamente importante.

Debe comunicar la propuesta de valor en aproximadamente **5 segundos**.

Debe contener:

* eyebrow opcional;
* headline poderoso;
* supporting copy;
* CTA principal;
* CTA secundario solo si aporta valor;
* prueba visual/social cuando corresponda;
* elemento gráfico que explique o refuerce el producto.

NO quiero un hero gigantesco vacío únicamente con texto centrado.

Busca una composición moderna.

Podemos utilizar:

* composición asimétrica;
* producto parcialmente visible;
* mockup;
* dashboard;
* fotografía;
* composición editorial;
* elementos superpuestos;
* cards flotantes discretas;
* estadísticas;
* social proof.

El Hero debe tener un **momento visual memorable**.

# STORYTELLING DEL SCROLL

Diseña la experiencia pensando en:

### 02 — Identificar

Mostrar el problema o situación que vive el usuario.

### 03 — Introducir

Presentar la solución.

### 04 — Demostrar

Mostrar cómo funciona.

### 05 — Convencer

Beneficios, diferenciadores, números, evidencia.

Testimonios, logos, métricas, casos de éxito o garantías.

Adapta la estructura según el negocio.
